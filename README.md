# 🌍 Explore the World – Hotel & Travel Explorer

## 📌 Project Overview

Explore the World is a Django-based hotel and travel exploration project.

The main purpose of this project is to help customers find suitable hotels based on their preferences such as price, rating, property type, bed type, facilities, dining options, and special offers.

This project is being developed as a practical Django project and will be enhanced with additional travel-related features in the future.

## ✨ Current Features

### 🏨 Hotel Management
- Add and manage hotels through Django Admin
- Hotel name and description
- Location
- Hotel images
- Price per night
- Rating
- Property type
- Number of bedrooms
- Bed type

### 🔎 Hotel Filtering
- Maximum price
- Minimum rating
- Property type
- Bed type
- Minimum bedrooms
- Wi-Fi
- Swimming pool
- Parking
- Airport transfer
- Gym
- Breakfast
- Lunch
- Dinner

### 🔽 Hotel Sorting
- S1 – Lowest Price → Highest Price
- S2 – Limited Time Offer
- S3 – Highest Rating

### 🔥 Special Offers
Hotels can have limited-time offers with discount percentages.
